# minimal-pomodoro-windows
# 极简番茄时钟

一款小巧的 Windows 桌面番茄时钟。暖石墨底色搭配象牙白数字，让界面只保留时间。

## 功能

- 25 分钟专注、5 分钟短休息、15 分钟长休息
- 每完成 4 次专注，进入长休息
- 开始、暂停、继续、重置和完成计数
- 正常倒计时与单个数字翻页两种显示模式
- 220 × 100 迷你窗口，支持拖动和置顶
- 声音与托盘提醒，可选自动开始下一阶段

## 下载与运行

进入本仓库的 Releases，下载 `Pomodoro-Windows.zip`。

解压后双击 `Pomodoro.exe` 即可运行，无需安装。

## 操作

- 点击开始：进入迷你计时窗口
- 双击迷你窗口数字：返回设置，计时不中断
- 双击设置界面的数字、文字或空白处：返回迷你窗口
- 迷你窗口按空格：暂停或继续
- 拖动数字：移动窗口
- 右击数字：打开操作菜单

## 说明

完成数量仅记录本次运行，退出后归零。系统通知设置和静音可能影响提醒。

使用 C# 与 Windows Forms 开发，编译方式见 `使用说明.txt`。
